# Atelier Lorem — portfolio studia architektury

Portfolio studia architektury „Atelier Lorem" zbudowane w React + Vite (TypeScript).
Prezentuje realizacje, profil studia i formularz kontaktowy.

## Stack

- React + Vite
- TypeScript

## Uruchomienie

```bash
npm install
npm run dev
```

Build produkcyjny: `npm run build`, podgląd: `npm run preview`.
